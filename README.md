# Amazon Sales Analytics Dashboard

## Overview
An interactive Power BI dashboard developed to analyze Amazon sales data and uncover insights into product performance, customer purchasing behavior, and key business metrics.

## Objectives
- Analyze sales trends and revenue performance
- Identify top-performing products and categories
- Monitor customer purchasing patterns
- Visualize key business KPIs

## Features
- Sales Performance Analysis
- Product Category Insights
- Revenue Tracking
- KPI Monitoring
- Interactive Filters and Visualizations

## Technologies Used
- Power BI
- Data Visualization
- Business Intelligence
- Microsoft Excel / CSV

## Dataset
The dataset contains Amazon product sales information, including:
- Product Categories
- Sales Metrics
- Revenue Data
- Product Performance Indicators

## Key Insights
- Identified top-performing product categories
- Analyzed sales trends across products
- Evaluated revenue-driving products
- Generated actionable business insights through dashboards
